# Floweb Introduction

Floweb is a lightweight floating browser that can convert websites into desktop widgets. It supports turning any website into a small window for browsing, allowing you to launch and run web pages like local applications, greatly improving the convenience and efficiency of daily operations. Whether you're monitoring real-time data, managing multiple accounts, or testing websites, Floweb can meet your needs.

## 📖 **Development Background**

Why was this software created? Originally, I wanted to use a Pomodoro timer website and wanted to pin it to the top. However, in the latest version of macOS, there was no configuration available to pin a browser webpage to the top. Some methods might work with older systems, but the latest versions no longer support them. During this time, I also researched some tools, but they either only supported macOS or only supported Windows, and for someone using both systems simultaneously, this was indeed quite rare. As a programmer, I always like to build something of my own. Additionally, eight years ago I created a navigation website called "Rumou Website", so I decided to combine the two concepts and created this little tool.

## ☺️ **Why Use Floweb?**

Floweb transforms web pages into desktop applications, freeing you from the hassle of constantly switching browser tabs. Whether you need to manage multiple social accounts simultaneously, monitor stock prices, track news updates, or test websites, Floweb provides professional and efficient solutions.

### 🌐**WebApps - Web Pages as Applications**

Quickly add commonly used websites or services, such as email, social media, online documents, project management tools, etc., to your desktop for one-click access. One URL equals one WebApp, with simple and straightforward operations that make it easy to convert your favorite web pages into convenient application forms.

**Easy Definition:**
- Automatically fetches high-definition logos from websites, and also supports custom icons
- Automatically recognizes website titles

**Multi-Account Support & Independent Data Storage (Windows Only):**
Each WebApp stores data separately and supports individual login, making it convenient to switch between different accounts to meet various scenario needs, such as managing multiple social media accounts or work accounts simultaneously. Data is isolated from each other, ensuring information security and convenience of use.

### 🛠️**Practical Auxiliary Features**

**Auto Refresh:**
Conveniently view the latest data without manually refreshing pages frequently, saving time and operational costs. Especially suitable for scenarios that require real-time attention to information updates, such as stock quotes, news, etc. Floweb can automatically refresh pages at the interval you set, ensuring real-time information updates.

**Resize:**
Freely adjust window size according to your actual needs, adapting to different content display and operation requirements, providing a more flexible user experience.

**Multi-Simulator (Multiple Sizes):**
Provides multiple size simulation environments, allowing you to test and experience in different device size scenarios, better adapting to various device types, ensuring applications display optimally on different screen sizes.

**User Agent:**
Can simulate User-Agents of various devices (including macOS Safari, Chrome, Android Chrome, Windows Chrome, Linux Chrome, macOS Edge, and Kindle, etc.), allowing you to simulate different device identities when accessing web pages, facilitating compatibility testing or meeting specific website requirements for different device access, enhancing the versatility and applicability of the application.

**JS Scripts:**
Supports JS scripts, providing users with richer customization and extension features to meet personalized needs.

**Open in Default Browser:**
Can directly open related content in the default browser, achieving seamless connection and facilitating users to further browse or process related information.

### 📌**Window Management**

**Window Pin:**
Can place important windows on top for easy viewing and operation at any time, ensuring key information is not blocked by other windows. No matter how many applications you have open, the pinned Floweb window will stay on top, ensuring important content is always within your sight.

**Window Transparency:**
Can adjust window transparency, allowing you to view window content while also paying attention to other interface information, improving multitasking efficiency and visual experience. By adjusting window transparency, you can browse web pages while keeping an eye on other content on your desktop, achieving a more flexible working style.
